Track Model Installation Guide

These instructions are intended for someone who can navigate Python Explorer and a Python file
If someone does not know these tools, these can be demonstrated by someone who does

Download:
1. Download TrackModel folder
2. Unzip folder if necessary
3. Progress to inside TrackModel folder and find this file

Reconfiguring track:
Option 1: Directly editing "Green Line.xlsx" and "Red Line.xlsx"
- Open file in Microsoft Excel
- Edit parameters
- All changed parameters will appear
- Only default values are integrated with other modules
- Start TrackModelMain.py
- Data automatically loaded from files
Option 2: Copying file
- Edit copy of file
- Start TrackModelMain.py
- Changes to track shape will not appear
- Only default values are integrated with other modules

Opening Track Model:
Option 1: Open TrackModelMain.py in preferred IDE with Python
Option 2: Open terminal in folder with TrackModelMain.py and run "python TrackModelMain.py"

Using Track Model:
- Hover over components to get more information
- Use temperature slider at top to set temperature
- Hover over failure options to find failure type
- Click failure type and click block arrow to appy failure type
