# Trains
## Installation Manual

### Step 1.
If you do not have python3 with a version 3.10 or greater, please download python from the windows store. 
Then Download the repository. 

### Open a Command Prompt.
Right click on the downloaded folder and hit "Open in terminal."

### Run the program
Enter the following commands into your terminal. 
```bash
python3 -m venv env
env/Scripts/Activate
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
python3 main.py
```
### Hardware
Plug in the wayside hardware via ethernet. Press connect on the Hardware Wasyside Controller.
